# React Investment Calculator

A modern React application that helps users calculate and visualize their investment growth over time. Built with React and Vite, this interactive tool allows users to input their initial investment, annual contributions, expected return rate, and investment duration to see detailed year-by-year projections.

## 🚀 Features

- Built with React 19 and Vite for optimal development experience
- Modern React practices and patterns
- Component-based architecture
- Responsive design
- ESLint configuration for code quality

## 📋 Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (Latest LTS version recommended)
- npm (comes with Node.js)

## 🛠️ Installation

1. Clone the repository:

```bash
git clone https://github.com/DennisAbinayo/Investment-Calculator.git
```

2. Navigate to the project directory:

```bash
cd react-essentials-practice
```

3. Install dependencies:

```bash
npm install
```

## 🖥️ Development

To start the development server:

```bash
npm run dev
```

This will start the Vite development server. Open [http://localhost:5173](http://localhost:5173) to view it in your browser.

## 🏗️ Building for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
